# Prompt: สร้าง note สรุปบทความเป็นภาษาไทย

ใช้ prompt นี้เวลาส่ง url/บทความมาให้สรุปเป็น note เก็บใน Obsidian vault

---

## Frontmatter (YAML header)

ถ้าบทความต้นฉบับมี YAML frontmatter ของตัว clipper อยู่แล้ว (title, source, author, published, created, description, tags) ให้ดึงมาใส่เป็นส่วนหัวของไฟล์ note ได้เลย เช่น:

```yaml
---
title: "ชื่อบทความตามต้นฉบับ"
source: "url ต้นฉบับ"
author:
  - "[[ชื่อผู้เขียน]]"
published: วันที่เผยแพร่
created: วันที่สร้าง note (วันนี้)
description: "คำอธิบายสั้นๆจาก clipper"
tags:
  - "clippings"
---
```

ไม่ต้องเขียน blockquote สรุป source/author ซ้ำในเนื้อหาอีก เพราะ frontmatter ครอบคลุมแล้ว

## เนื้อหา

- เขียนสรุปด้วยคำพูดของตัวเอง ไม่แปลตรงทุกประโยคจากต้นฉบับ
- คำเทคนิค, คำสั่ง (kubectl, bash ฯลฯ), YAML, code block คงไว้เป็นภาษาอังกฤษเหมือนเดิม
- จัดโครงสร้างด้วย heading (`##`, `###`) ตามหัวข้อของบทความ
- ถ้ามีตารางเปรียบเทียบในบทความ ให้ทำเป็น markdown table
- ปิดท้ายไฟล์ด้วยลิงก์ source ของบทความต้นฉบับ

## รูปภาพ

- ไม่ดาวน์โหลดรูปมาเก็บ ใช้ url รูปจากต้นฉบับแบบ `![](url)`
- ใต้รูปแต่ละรูป เว้น 1 บรรทัดเปล่า แล้วเขียนคำอธิบายสั้นๆว่ารูปนี้คืออะไร (plain text)
- ถ้าไม่ได้เห็นรูปจริง ให้บอกว่า caption เป็นการอนุมานจากบริบท และพร้อมแก้ตามภาพจริงถ้าผู้ใช้ส่งมาตรวจ

## Format

- ห้ามใช้ bold (`**`) และ italic (`*`) ในเนื้อหาทั้งหมด รวมถึง caption รูป
- ใช้ list/table เท่าที่จำเป็นสำหรับความชัดเจน

## ชื่อไฟล์

- รูปแบบ: `ชื่อผู้เขียน_หัวข้อสั้นๆ.md` (ไม่เอา title เต็มของบทความ)
- ตัวพิมพ์เล็กทั้งหมด
- ใช้ `_` แทนช่องว่างทั้งหมด (ไม่มี space ในชื่อไฟล์)

## โฟลเดอร์ปลายทาง

- เก็บใน `notes/k8s/` (หรือโฟลเดอร์ย่อยของ `notes/` ตามหัวข้อของ note)
- ถ้ามี note หลายตัวในหมวดเดียวกัน ค่อยพิจารณาแยก subfolder ตามหมวดย่อยทีหลัง
